# aliou-skills

Claude Code plugin marketplace by [Aliou Barry](https://github.com/barryaliou980).

## Setup

```
/plugin marketplace add barryaliou980/aliou-skills
```

## Plugins

| Plugin | Description | Install |
|---|---|---|
| [feature-status-tracker](https://github.com/barryaliou980/feature-status-tracker) | Turns a Markdown feature table into an autonomous dev pipeline: clarify each feature, then one branch + one PR per feature until the table is done. English or French. | `/plugin install feature-status-tracker@aliou-skills` |
| [demo-video-generator](https://github.com/barryaliou980/demo-video-generator) | Generates a professional demo video (.mp4) of your SaaS app from a user journey — Playwright captures, Remotion animation, Stripe/Linear product-tour style. | `/plugin install demo-video-generator@aliou-skills` |
